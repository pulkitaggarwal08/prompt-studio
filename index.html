The fundamentals

What a prompt actually is.

A prompt is a brief. It sets the model's role, describes the task, and constrains the shape of the answer. Everything else is decoration.

A one-line question gets a generic answer because a one-line brief would get a generic deliverable from a person too. The lift from a bad prompt to a great one isn't longer text — it's structure. Same information, better organised, produces a dramatically better response.

That is what a framework is: a proven structure. Prompt Studio reads your rough request, applies the framework you chose (or the one it judges best), and writes the fully-formed prompt for you — so you get the structure without doing the work.

The four signals every model uses
  • Role. Primes vocabulary and reasoning style.
  • Task. The single thing to produce.
  • Context. What the model needs to know to reason well.
  • Format. The container the answer arrives in.

Every framework in the library rearranges and expands these four signals for a different purpose.
